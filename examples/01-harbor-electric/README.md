# 01-harbor-electric

Worked example: an 11-person Long Island electrical contractor. The trades
case, and the one to read if you work with your hands.

Sixteen tasks, a clean stated rate, and two lines that come back **Hand down,
no AI** -- the kit refusing to claim software makes phone calls, and finding
the typing wrapped around them instead.

- `session.md` -- the actual back-and-forth: the dump, the four questions per
  task, and the arithmetic being shown.
- `tasks.md` -- the working file the pipeline saved as it went.
- `audit.html` -- the finished one-page audit.

All names and numbers are invented for illustration. This is a derived
artifact: it must be re-derived whenever a grading rule changes.
