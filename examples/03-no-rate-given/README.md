# 03-no-rate-given

Worked example: a solo licensed insurance producer with one part-time
assistant. The hours-only path.

The owner declines to state what she makes an hour. The kit does not guess,
does not substitute an industry average, and prints no dollar figure anywhere
on the page -- and the audit is still worth handing over.

- `session.md` -- the back-and-forth, including the rate gate.
- `tasks.md` -- the working file the pipeline saved as it went.
- `audit.html` -- the finished one-page audit, hours only.

All names and numbers are invented for illustration. This is a derived
artifact: it must be re-derived whenever a grading rule changes.
