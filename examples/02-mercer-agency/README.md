# 02-mercer-agency

Worked example: a 6-person marketing agency. This is the refusal doing its
job.

Three tasks land in the un-finished queue because they cannot be described
concretely enough to price, and the owner's reaction to that is the most
useful part of the session.

- `session.md` -- the back-and-forth, including the refusals.
- `tasks.md` -- the working file the pipeline saved as it went.
- `audit.html` -- the finished one-page audit.

All names and numbers are invented for illustration. This is a derived
artifact: it must be re-derived whenever a grading rule changes.
