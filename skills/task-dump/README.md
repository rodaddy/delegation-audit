# task-dump

Stage 1 of the pipeline. `SKILL.md` puts the AI into capture-first listening
mode while the owner empties the week onto the table.

It captures the tasks in the user's own words and holds all grading, advice,
and action until the user clearly changes modes. Adds memory joggers and an
eight-task floor. Triggered by "task dump", "dump my week", "audit my week",
or similar.
