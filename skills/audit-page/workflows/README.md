# Workflows

The step-by-step procedures the `audit-page` skill follows.

- `build-audit.md` -- build a finished `audit.html` from a graded `tasks.md`,
  including the arithmetic (step 6) and the final page checks (step 10): no
  `{{` left, no external requests, headline numbers reproduced in the
  arithmetic block, and the two split figures summing to the reclaimed total.
- `update-audit.md` -- change an existing audit, either as a surgical edit or
  as a full re-audit.
