# grill-my-tasks

The stage 2 shortcut trigger. `SKILL.md` is a thin, explicitly-invoked entry
point ("grill my tasks", "grade these") into the same one-task-at-a-time
interview that `task-grilling` defines.

It carries `disable-model-invocation: true`, so the user asks for it by name.
Mirrors the `grill-me` pattern from the MIT-licensed
github.com/mattpocock/skills `productivity/grill-me`.
